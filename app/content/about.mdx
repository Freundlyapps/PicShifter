# About PicShifter

## Our Mission

PicShifter is dedicated to providing fast, free, and secure image processing tools for everyone. We believe that powerful image manipulation should be accessible without complicated software installations or subscriptions. Check our [FAQ](/faq) to learn more about our service.

## Core Features

### Image Conversion
Transform your images between multiple formats instantly:
- JPEG/JPG to PNG
- PNG to JPEG/JPG
- WebP conversion
- AVIF support
- TIFF processing
- SVG handling

### Image Optimization
- Smart resizing
- Quality adjustment
- File size reduction
- Format optimization

### Special Effects
- Grayscale conversion
- Blur effects
- Brightness adjustment
- Contrast enhancement
